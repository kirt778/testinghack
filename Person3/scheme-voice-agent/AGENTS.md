# Project rules (read before coding; paste into your AI assistant too)

1. NEVER ask for or store Aadhaar, bank details, phone numbers, or OTPs.
2. The LLM never decides eligibility. Only the rule engine does.
3. Unknown values are `None`, never 0 or "".
4. Language codes: hi, ta, bn, en.
5. Every scheme shown must have source_url and date_checked.
6. Never edit another person's folder without telling them.
7. Never edit shared/contracts.py without agreement from all three.
8. Never commit API keys. Use a .env file or Replit Secrets.
